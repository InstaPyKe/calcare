# Calcare - Smart Loans for Smart People

Calcare is a premium, modern mobile-first loan application platform designed specifically for fast, intuitive, and secure short-term loan awards. 

## Features
- **Oblique Lobster Typography**: Pure green slanted brand graphics with interactive logo breathing/pulse animations.
- **Dynamic Limit Allocation**: Random first-time loan limits ranging between KSh 500 and KSh 5,000, with scaling paths unlocking limits up to KSh 200,000 upon timely repayment.
- **Realistic Repayment Calculator**: Recalculates total dues, markups, and installments dynamically with dates auto-updating relative to today.
- **Strict Format Validation**: Real-time validation for Kenyan phone numbers, human name fields, National IDs, PINs, and birthplaces to prevent invalid applications.
- **Polished Document Upload**: Features drop-zone selections, format rules, maximum size validation, and interactive dynamic image thumbnail previews.
- **OTP Bypass option**: Option to skip SMS verification and proceed to document uploads instantly.
- **Animated Sparkling Tagline**: Beautiful vector golden stars that sparkle asynchronously to welcome applicants.
